SuperDev Pro — Web Developer Toolkit

Privacy policy

What the extension does

SuperDev Pro — Web Developer Toolkit inspects and edits web page styles, text, layout and images, and supports screenshots and element export. Page inspection and comparison take place in your browser.

Data handled locally

The tools access page DOM content, computed styles, image URLs, text, and screenshot pixels as needed. Settings are retained in Chrome extension storage. Exported HTML/CSS, downloaded images, and screenshots are saved to files you choose. Page content may include personal or confidential information depending on the page you inspect.

Optional network actions

Export to CodePen sends the selected element’s HTML and CSS to https://codepen.io/pen/define when you choose that action. The font changer requests selected web fonts from Google Fonts. Image replacement and image download features may request images from the source URLs you select. Those services receive the submitted content or normal request information such as your IP address and handle it under their policies. The developer does not operate a collection server.

Permissions

Active tab and scripting support the developer tools; downloads saves requested files; storage remembers preferences. Host access and a content script on supported web pages allow tools to function across sites. The toolkit does not use this access for analytics or advertising.

Retention and deletion

Preferences remain until cleared or the extension is removed. Uninstalling removes extension storage but does not remove exported files, changes saved elsewhere, or content you sent to CodePen. Delete those separately where they are stored.

Developer services and limited use

The extension contains no developer-operated analytics, advertising, or telemetry service. The developer does not sell user data. Data is used to provide the extension’s stated features and is not used for advertising, creditworthiness, or lending decisions. Use and transfer of user data comply with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Contact

Questions or deletion requests: admin@nightowldevelopers.com. The developer cannot delete copies held by services you use; contact those services directly.
