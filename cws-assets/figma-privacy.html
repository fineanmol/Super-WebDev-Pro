Figma Design Reviewer

Privacy policy

What the extension does

Figma Design Reviewer compares selected web page elements with Figma design nodes. It is an independent extension and is not affiliated with Figma.

Data stored on your device

Chrome extension local storage holds your Figma personal access token, account name and email returned during sign-in, selected design data, preview image URLs, saved nodes, and preferences. The page structure and computed styles you inspect are processed locally for comparison.

Network requests

Your token is sent in an authentication header only to https://api.figma.com, together with the file and node identifiers needed to retrieve the designs you request. Preview images load from the HTTPS image delivery URLs returned by Figma. These image hosts receive ordinary request information such as your IP address; your Figma token is not attached to image requests. Inspected web page content is not uploaded to the developer or Figma.

Permissions

Storage saves settings and designs. Active tab and scripting access enable inspection of the page you choose. Side panel access displays the interface. Host access to api.figma.com supports authenticated design retrieval.

Retention and deletion

Stored settings and designs remain until removed. Sign out removes the saved token and account details; Clear all removes saved nodes. Uninstalling removes extension local storage. Revoke a token in Figma settings to invalidate it. Figma independently controls retention of requests and design files under its policies.

Developer services and limited use

The extension contains no developer-operated analytics, advertising, or telemetry service. The developer does not sell user data. Data is used to provide the extension’s stated features and is not used for advertising, creditworthiness, or lending decisions. Use and transfer of user data comply with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Contact

Questions or deletion requests: admin@nightowldevelopers.com. The developer cannot delete copies held by services you use; contact those services directly.
